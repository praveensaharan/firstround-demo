Under the Hood

The Dialogue Map Language

// Each node is a question with branches
"greet_open": {
  "kind": "ask",
  "say": "Tell me about an LLM
        feature you shipped.",
  "motion": "greeting",
  "emotion": "curiosity",
  "branches": [
    { "when": "Names a real shipped feature",
      "to": "deep_retrieval" },
    { "when": "Vague or no real ownership",
      "to": "push_ownership" }
  ],
  "fallback": "push_ownership"
}

Adaptive routing at 1–1.5s — the LLM reads the answer and picks the next node. Fast enough to feel like thought, not a kiosk.

8 named gesture slots — the map says probing; one click in the motion editor changes what probing means for every question.

Emotion + intensity per node — the avatar looks visibly unconvinced by a thin answer. That signal is the interview.

Visual editor — recruiters can read and edit the map in the browser, no JSON required.
